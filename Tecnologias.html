Tecnologias para Desenvolvedores

Conheça algumas das principais tecnologias utilizadas no desenvolvimento web.

HTML

O HTML é utilizado para estruturar o conteúdo da página.

CSS

O CSS é utilizado para definir a aparência e apresentação dos elementos.

GIT

O GIT é utilizado para criar e salvar diversas versões do código, sendo possível resgatar versões antigas em caso de crashes.
